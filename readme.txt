Váš balík @font-face je pripravený.

Pred publikovaním overte, že licencia povoľuje použitie fontu na webe v požadovaných doménach, projektoch a pri očakávanej návštevnosti.

1. Nahrajte súbory webfontov aj stylesheet.css na web. Ak zmeníte cesty alebo názvy, upravte aj URL adresy v štýloch.

2. Skopírujte vygenerované CSS do hlavného súboru štýlov alebo samostatne načítajte stylesheet.css.

3. Použite deklarovanú rodinu fontov na vybrané prvky cez vlastnosť CSS font-family.

4. Stránku otestujte v prehliadači, overte úspešné načítanie súborov a ponechajte v zozname font-family vhodný záložný font.
